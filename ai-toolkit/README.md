# Personal AI Toolkit

## Purpose

This toolkit contains reusable engineering guidance that applies across all software projects.
The goal is to provide consistent engineering practices, workflows, and decision making.
These documents supplement, but never replace, explicit user instructions.

---

# Startup Procedure

At the beginning of a new task:

1. Read this README.
2. Read the constitution.
3. Read the required workflow.
4. Read any referenced standards.
5. Read any referenced principles.
6. Read project-specific documentation if available.

---

# Directory Structure

constitution/
    Fundamental operating rules.

workflows/
    Step-by-step procedures.

prompts/
    Short reusable conversation prompts.

standards/
    Engineering standards.

principles/
    Decision frameworks.

checklists/
    Verification lists.

templates/
    Document templates.

playbooks/
    Technology-specific guidance.

---

# Instruction Priority

When instructions conflict, use the following order.

1. User instructions
2. Project-specific AI documentation
3. Workflow
4. Constitution
5. Standards
6. Principles

---

# General Rules

Never skip required documents.
If a workflow references another document, read it before continuing.
Do not duplicate instructions that already exist elsewhere.
Ask for clarification if required information is missing.
