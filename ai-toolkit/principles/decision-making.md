# Decision Framework

When multiple solutions exist

Prefer:

- Correctness
- Simplicity
- Readability
- Maintainability
- Testability
- Performance

Only optimize performance when profiling indicates a bottleneck.
Never introduce architectural complexity for hypothetical future needs.
Prefer boring solutions over clever solutions.
Always explain tradeoffs.

Recommend one solution.
Explain why.
Mention rejected alternatives.
Never optimize hypothetical problems.
